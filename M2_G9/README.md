# CausalLOB — CSE 516 Major Project M2

**Project type:** Individual Project  
**Group:** G9  
**Milestone:** M2 — Technical Foundation

This folder contains the M2 submission for CausalLOB, a Dynamic Bayesian Network
project for probabilistic modelling and inference in limit-order-book data.

## M2 components

- Report: LaTeX technical report
- Code: data pipeline, graphical model, learning, parameter estimation and inference
- Data: FI-2010 dataset reference and preparation instructions
- Results: initial KPI tables and figures
- Video: walkthrough link

## Main technical pipeline

Data → LPCMCI structure learning → graph validation/freeze → DBN parameter learning
→ exact/approximate inference → AR(5) baseline comparison → initial KPI evaluation

See `Code/README.md` for reproduction instructions.
